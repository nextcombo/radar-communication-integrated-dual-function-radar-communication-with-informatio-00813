# Radar Communication Integrated: Dual-Function Radar Communication with Information Encapsulation via Sidelobe Control and Waveform Diversity [with MATLAB Code]

Introduction Driven by the desire to reduce installation and hardware costs, as well as driven by the need for RF spectrum development, the sharing of system platforms and public bands between radar and communication has become a primary goal in guiding active sensing and wireless technology. The coexistence of radar and wireless communication systems can alleviate bandwidth competition and complement cognitive radio [3] and cognitive radar [4] functions, enhancing spectral utilization and efficiency. In other words, the coexistence of two platforms within the same frequency band can be consistent with the continuous search and utilization of available spectrum [2]-[9]. However, the sharing of spectrum resources and the occupation of the same frequency bandwidth require effective methods to limit cross-interference between the two system functionalities and appropriately apply the spatiotemporal freedom that is enabled by advances in waveform design and the widespread use of multi-sensor transmit/receive configurations.
The sharing of spectrum and the use of common transmission platforms between radar and communication requires operators to define the main system and auxiliary system functionalities based on requirements for power allocation and beam directional preferences. Issues of incorporating communication symbols into radar backscatter have been discussed in [10] and [11]. It has been reported in many papers that communication is a secondary function of radar [12]-[14]. In [13], it was reported that communication signals were embedded into radar transmission.
Recently, an information embedding method using time modulation arrays was reported in [14]. By adjusting the phase of the array elements from pulse to pulse, the sidelobe level (SLL) is introduced to the expected communication receiver. During each radar pulse, the communication receiver detects the SLL and interprets the associated information symbol. Although the waveform does not change from pulse to pulse, it is difficult to design multiple emission power distribution patterns with the same main lobe using time modulation arrays. This difficulty arises from the fact that the optimization criteria involved in the design are highly nonlinear and require high computational demands.
A new dual-function radar communication method is introduced, namely the combination of waveform diversity and sidelobe control. Information bits are embedded using multiple orthogonal waveforms. Sidelobes directed towards the communication direction are controlled to have two different levels. This is achieved by designing two transmission beamforming weight vectors. All waveforms are transmitted simultaneously, with each waveform containing one bit. The receiver interprets the bit associated with a specific waveform as either 0 or 1 based on whether the waveform is a radiation waveform, respectively on the said first or second transmission weight vector. It should be noted that most modern pulsed radar systems support pulse repetition frequencies within the kHz range [15]-[17], thus enabling a total data rate of several thousand bits per second through the inclusion of several bits per pulse.When the number of array elements is large, higher values can be used, which leads to higher data rates. In addition to waveform diversity, other types of diversity such as polarization can also be combined.
The proposed technology has the following attributes: (i) Communication messages can be transmitted to either a single or multiple communication directions, as long as they are outside the main lobe of the system's primary radar function; (ii) The communication process inherently is secure, unintercepted from directions other than those pre-allocated; (iii) Decoding each bit at the receiver is independent of the adjacent bits in the sequence; (iv) A set of waveforms is sent within each radar pulse, enabling the radar to perform coherent processing; (v) Waveform diversity allows the radar to operate in a multi-input multi-output (MIMO) mode; and (vi) If the receiver is mounted on a mobile platform, communication directions can be adaptively adjusted. The proposed method was validated through simulation examples, outperforming the recently developed method in [14].
In this section, we develop a DFRC signal model that employs waveform diversity and sidelobe control. The proposed system and the one reported in [14] are special cases of the development model, which will become evident in the following sections.
Consider a DRFC system equipped with a dual-function transmit array, a radar receive array, and (or) a communication receive array. The transmit and radar receive arrays are composed of transmit and receive antennas respectively, arranged in any straight line shape. Without loss of generality, we assume that the radar transmit and receive arrays are closely spaced, such that the spatial angles of the target relative to both arrays are the same in the far field. The dual-function transmit array aims to embed information into the direction of the communication receiver as a secondary task, namely, radar operation, without affecting the main task of the DFRC system. The transmit array is used to focus the transmit power within the main beam of radar operation.
